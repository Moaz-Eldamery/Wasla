# AI service (the AI subsystem)

The Python FastAPI AI service, managed with uv. This README also covers its own files here and in `app/`.

**Rule:** Reachable only from the core. No access to the clinical database. Nothing that identifies a patient is sent to the LLM.

## Files

- `pyproject.toml`: dependencies, plus ruff and pytest settings. Add packages with `uv add`.
- `uv.lock`: exact dependency versions (generated by uv).
- `.python-version`: the Python version (3.12).
- `Dockerfile`: the service image. Builds from the repo root.
- `app/__init__.py`: makes `app` a package.
- `app/main.py`: the FastAPI app; `GET /health`.
- Planned: `app/llm.py` and `app/privacy.py` (KAN-22).

`.venv/` is created by `uv sync` and isn't committed.
